# Facundo Rodriguez — Personal website

Static portfolio for [rodriguezfacundo.com](https://rodriguezfacundo.com), built with HTML, CSS, and JavaScript.

## Preview

Run `npm run dev` and open http://localhost:3000.

## Deploy

The site is ready to deploy on Vercel from the `dist/` directory. It has no build step or backend. For another static host, publish the contents of `dist/` and configure your domain and HTTPS with that provider.

## Update content

- Edit `dist/index.html` for page content.
- Edit `dist/styles.css` for styling and `dist/script.js` for behavior.
- Replace `dist/assets/Facundo-Rodriguez-CV.pdf` to update the downloadable CV.

The experience section and CV are based on Facundo's supplied résumé. Project details were provided by Facundo; no private customer data is displayed.
